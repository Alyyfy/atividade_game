# 🎮 Mini Desafio HTML - Loja de Games

## 📋 Descrição

Esta atividade consiste na criação de uma página web simples para uma loja de jogos chamada **Indie Games**. O objetivo foi utilizar conceitos básicos de **HTML** para apresentar informações sobre a loja, consoles disponíveis e preços de jogos.

## 🎯 Objetivo

Desenvolver uma página HTML compacta e funcional, utilizando elementos básicos da linguagem:

- Títulos e parágrafos;
- Textos em **negrito** e *itálico*;
- Listas;
- Links;
- Imagens;
- Tabelas;
- Separadores de conteúdo.

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- Navegador Web

## 🎮 Conteúdo da Página

### 🕹️ Loja Indie Games

A página apresenta o nome da loja **Indie Games** e uma breve descrição sobre seus produtos.

### 🔗 Link Externo

Foi adicionado um link para **"Ver Preços no Instagram"**, permitindo acessar uma página externa.

### 🖼️ Imagem

A página contém uma imagem relacionada ao tema de jogos para representar visualmente a loja.

### 🎮 Consoles Disponíveis

Foi utilizada uma lista não ordenada contendo:

- PlayStation 5 (PS5 / PS5 Slim)
- Xbox Series X
- Xbox Series S
- Nintendo Switch

### 💰 Tabela de Preços

A página apresenta uma tabela com jogos, consoles e seus respectivos preços:

| Jogo | Console | Preço |
|---|---|---:|
| Tunic | Xbox Series X/S | R$ 85,00 |
| Hollow Knight | Nintendo Switch | R$ 70,00 |
| Stray | PlayStation 5 | R$ 120,00 |

## 📚 Conceitos de HTML Utilizados

Durante a atividade foram utilizados diversos elementos básicos do HTML:

- `<h1>` e `<h2>` — títulos;
- `<p>` — parágrafos;
- `<b>` e `<i>` — formatação de texto;
- `<ul>` e `<li>` — listas;
- `<a>` — links;
- `<img>` — imagens;
- `<table>`, `<tr>`, `<th>` e `<td>` — tabelas;
- `<hr>` — separação de seções.

## ✅ Conclusão

A atividade demonstra como é possível criar uma página simples de uma loja de games utilizando apenas **HTML**, sem a necessidade de CSS ou JavaScript. O projeto reúne diferentes elementos fundamentais da linguagem e mostra como eles podem ser organizados para apresentar informações de maneira clara e funcional.
